# TTS 工具说明

TTS功能已启用。你可以通过 `tts` 工具直接发送一段语音。

## 使用方式

调用 `tts` 工具，参数如下：
- `target`：发送目标，格式同 `chat` 工具
- `text`：要转换为语音的文本
- `options`：TTS 后端的额外参数（可选，**通常不需要提供**）

## 重要：默认行为

**默认情况下，不要传递 `options` 参数。**

不传 `options` 时，TTS 会使用默认参考音频作为情感参考，合成效果自然、稳定。

只有在需要**明确的情感表达**（如"愤怒地说"、"悲伤地"）时，才使用情感向量参数。

## 情感参数（仅在需要时使用）

`options` 对象支持以下参数：

| 参数 | 类型 | 说明 |
|------|------|------|
| `emo_vector` | number[8] | 8维情感向量：[喜, 怒, 哀, 惧, 厌恶, 低落, 惊喜, ?]，每个值 0.0-1.0 |
| `emo_alpha` | number | 情感强度权重，0.0-1.0，默认 1.0 |

### 情感向量说明

8维情感向量分别代表：
1. 喜 (Joy)
2. 怒 (Anger)
3. 哀 (Sadness)
4. 惧 (Fear)
5. 厌恶 (Disgust)
6. 低落 (Depression)
7. 惊喜 (Surprise)
8. 未知

### 示例

**默认用法（推荐）**：
```json
{
  "target": { "type": "group", "id": "123456" },
  "text": "你好呀～"
}
```

**需要特定情感时**：
```json
{
  "target": { "type": "group", "id": "123456" },
  "text": "你怎么能这样！",
  "options": {
    "emo_vector": [0.0, 0.8, 0.0, 0.0, 0.3, 0.0, 0.0, 0.0],
    "emo_alpha": 0.9
  }
}
```

## 注意事项
- 语音消息适合简短、口语化的表达，不要让文字过长。
- 一次只转换一条语音，不要连续发送多条语音。
- 语音生成需要时间。
- 目前TTS只是锦上添花的功能，没有需要的时候不要使用。
