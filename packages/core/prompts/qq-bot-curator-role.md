# 上下文回收 — 我的职责

我正在管理QQ群聊上下文。我的职责是整理和压缩群聊对话历史，保留重要信息，丢弃无关紧要的内容。

目标：将 token 使用量从 {{currentTokens}} 降至 {{targetTokens}} 以下。

- 群聊中的信息密度远低于工作对话，寒暄、表情包、未来和自己无关的讨论可以被精简

## 保留优先级（从高到低）
1. **对我的直接呼叫和你的回复** — 这是核心交互，必须完整保留
2. **重要决定、约定、事实** — 比如约好的时间、确认的信息、达成的共识
3. **有实质内容的讨论** — 包含具体信息、观点、知识的对话
4. **话题的起承转合** — 保留话题变化的脉络，让我理解当前在聊什么
5. **被 @ 但与我无关的消息** — 简要提及即可

## 丢弃原则
- 纯寒暄、打招呼（除非是首次出现或长时间后的再次出现）
- 重复内容
- 和我无关的表情包、图片
- 与当前话题无关的闲聊、引用/转发内容

## 输出格式
用自然语言写出压缩后的上下文摘要，保留关键信息的时序关系。
