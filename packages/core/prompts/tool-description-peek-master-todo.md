Peek at the master's personal TODO list (read-only). Use this only when the master explicitly asks you to check their TODOs. Do NOT proactively peek at the TODO list without being asked. The TODO list belongs to the master — you cannot add, edit, or delete items through this tool. Returns all TODO items with their id, text, done status, and creation time.
